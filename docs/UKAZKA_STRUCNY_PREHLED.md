# Stručný přehled praktické ukázky - Destinote

## ⏱️ Doporučený čas: 10-15 minut

---

## 🎯 HLAVNÍ BODY K UKÁZCE

### 1. Úvodní stránka (1 min)
- Design a hlavní funkce
- Statistiky komunity

### 2. Přihlášení (30 sec)
- Ukázka registrace/přihlášení
- Použijte testovací účet

### 3. Dashboard - Mapa cest (2 min) ⭐ DŮLEŽITÉ
- Interaktivní mapa
- **Označte 3-5 zemí** (např. ČR, Německo, Itálie, Thajsko)
- Ukázka aktualizace statistik

### 4. Detail země (1 min)
- Klikněte na Thajsko nebo jinou zemi
- Ukázka informací z REST Countries API
- Rozloha, hlavní město, populace, jazyky, měny

### 5. Vytvoření článku (2 min)
- Editor článků
- Upload obrázku
- Výběr destinace

### 6. Komunita (1 min)
- Feed článků
- Lajky a komentáře

### 7. Profil uživatele (1 min)
- Statistiky
- Mapa navštívených zemí
- Články

### 8. Žebříček (30 sec)
- Top cestovatelé
- Ranking systém

### 9. Vyhledávání (30 sec)
- Vyhledání "Thajsko" nebo jiné země

### 10. Závěr (1 min)
- Shrnutí technologií
- Zdroje dat
